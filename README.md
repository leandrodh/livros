## Arquivos

- `livros.csv` — base única (edite aqui as notas)
- `generos/` — páginas geradas por categoria e autor
- [perfil-e-recomendacoes.md](perfil-e-recomendacoes.md) — análise de gosto e próximos livros
- `scripts/gerar.py` — regenera as páginas a partir dos dados

## Preferências

- Formato preferido: audiobook, em português ou espanhol.
- Inglês só com atenção total (não ideal para ouvir em treino).
- Itens marcados `(a confirmar)` precisam de autor/edição revisados.
